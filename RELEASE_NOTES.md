Kinetic Cut 1.1.0 adds a self-contained Windows installer with editing and English
caption generation included. Optional Android/iPhone tools, local face/background
analysis and vocal separation can be selected during installation or downloaded
later. Download screens show sizes, confirmation, progress and cancellation.

Missing components have download controls in the effects library and a blurred
phone page with a download panel. Cache Manager can remove installed optional
packs and immediately restore their download state. Power Bin metadata and its
referenced sources are preserved by uninstall.

Startup checks offer verified GitHub updates with OK, Cancel and Don't show again
for that release. File > Check for updates checks manually, including dismissed
releases. Offline checks report connection errors instead of claiming up to date.

Personal projects, media libraries, Power Bin data and downloaded music are excluded
from releases. The personal-transfer installer retains existing caption fonts,
templates and emoji resources with their available notices. Owner-supplied font
binaries are outside source history. Editing operations are unchanged.
